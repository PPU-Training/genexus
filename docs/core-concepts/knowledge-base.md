# Knowledge Base

Knowledge Base adalah repositori yang menyimpan **pengetahuan aplikasi**, bukan hanya kode.  
Di dalamnya terdapat definisi struktur data, aturan bisnis, dan tampilan aplikasi.

---

## Konsep Utama
- Tidak fokus menulis kode manual
- Mendefinisikan **apa yang ingin dibuat**
- GeneXus akan generate aplikasi secara otomatis

---

## Isi dari Knowledge Base

### 1. Data Model
- Mendefinisikan struktur database
- Contoh: Transaction (tabel + aturan bisnis)

### 2. Business Logic
- Rules (aturan bisnis)
- Procedures (proses backend)
- Events (aksi berdasarkan trigger)

### 3. User Interface
- Web Panel / Panel
- Form input dan tampilan data

### 4. Objects
Objek utama:
- Transaction
- Procedure
- Web Panel
- Data Provider
- Work With Objects
