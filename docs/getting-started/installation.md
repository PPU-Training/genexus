# GeneXus Installation Guide

Panduan ini mencakup:
- Install **GeneXus Trial**
- Install **GeneXus 18 (Full Version)**

---

# 🧪 Install GeneXus Trial

## 1. Download Trial

1. Buka halaman:
   - https://training.genexus.com/en/download-genexus-trial
2. Masukkan email pada form
3. Klik **Download / Submit**

---

## 2. Cek Email

1. Buka inbox email
2. Cari email dari GeneXus
3. Klik link download installer di dalam email

![Example](https://raw.githubusercontent.com/PPU-Training/genexus/refs/heads/main/assets/images/getting-started/ss-email.png)

> Jika tidak ada, cek folder **Spam / Promotions**

---

## 3. Download Installer

1. Klik link dari email
2. Download file installer GeneXus

---

## 4. Install GeneXus

1. Jalankan file `.exe`
2. Ikuti setup:
   - Next → Install → Finish
3. Tunggu hingga selesai

---

## 5. Aktivasi Trial

- Biasanya otomatis aktif
- Jika diminta:
  - Gunakan email yang didaftarkan

---

### ✅ Summary Trial

- Input email
- Cek email
- Download installer
- Install
- Trial siap digunakan

---

### 💡 Tips

- Gunakan email aktif (Gmail direkomendasikan)
- Pastikan internet stabil
- Jalankan sebagai **Administrator** jika error

---

# 💻 Install GeneXus 18 (Full Version)

## 1. Download & Install

1. Download:
   - http://www.genexus.com/v18-download
2. Jalankan installer
3. Ikuti wizard instalasi

---

## 2. Persiapan Sebelum Install

- Pastikan device memenuhi:
  - Hardware requirements
  - Software requirements
- Cek dependensi yang dibutuhkan

> Setup akan memandu proses instalasi

---

## 3. Aktivasi Lisensi

### First Time User
- Ikuti panduan aktivasi lisensi

### Existing User
- Upgrade lisensi ke GeneXus 18
- Bisa digunakan bersamaan dengan versi lama
